# Institutional scope

## Assets
BTC, ETH, SOL only.

## Evidence families
1. Price structure / trend
2. Momentum
3. Realized short-horizon volatility
4. Order flow / CVD proxy from trade aggressor side
5. Multi-level top-of-book liquidity and imbalance
6. Derivatives: open interest, funding, mark/spot basis and liquidation-flow bias
7. Multi-timeframe alignment: 1m, 5m, 15m
8. Cross-asset regime, with BTC as a primary regime reference
9. Data freshness and conflict detection

## Decision policy
No single indicator creates a trade. Entry states require a sufficiently strong combined evidence score, fresh core market data and no material conflict. Conflicts or stale data downgrade to WAIT/WATCH.

## Monitoring
Monitoring is explicitly user-controlled. OFF closes market-data WebSockets and stops the analysis service. ON starts the foreground monitoring service. WebSockets use bounded exponential reconnect while monitoring remains enabled.

## Risk
This is decision support, not a guarantee of profit. Live order execution is disabled. MANAGE is reserved for a future validated paper-position/trade-management layer. Exchange-specific execution and risk controls must be separately validated before any live-trading feature is introduced.
